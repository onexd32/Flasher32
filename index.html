Sebelum mulai

Flashing checklist

Jangan terburu-buru. Pastikan semua persiapan sudah benar untuk mengurangi risiko bootloop atau kehilangan data.

STEP 01

Kenali model HP

Pastikan nomor model dan codename cocok persis dengan file yang digunakan.

STEP 02

Backup data

Simpan foto, dokumen, dan file penting ke tempat lain sebelum mulai.

STEP 03

Siapkan file

Unduh firmware, ROM, dan tools dari sumber resmi atau pengembang tepercaya.

STEP 04

Ikuti instruksi

Baca seluruh panduan untuk model dan versi perangkat yang tepat.

⚠️ Catatan keamanan: Flashing, unlock bootloader, dan root dapat menghapus data, membatalkan garansi pada perangkat tertentu, menurunkan keamanan, atau menyebabkan perangkat tidak bisa menyala jika salah langkah. Jangan gunakan file untuk model lain. Pastikan baterai cukup dan pahami cara pemulihan sebelum melanjutkan.
